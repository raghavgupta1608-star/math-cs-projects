# Projects

Small programs I wrote for fun while learning Python and probability.

- `blackjack/` - command line blackjack against a dealer
- `poker/` - five card draw poker against the computer, plus a hand odds simulator
- `black_scholes/` - option pricing with the Black-Scholes formula and a Monte Carlo check

Run any of them with Python 3, for example:

    python3 blackjack/blackjack.py
    python3 poker/poker.py
    python3 poker/odds.py
    python3 black_scholes/bs.py

No extra packages needed.
